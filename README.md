# Cold Deep-Ethics Testing of Default AIs

> **EARLY BETA — public research archive under construction**

> Testing Deep Ethics Reasoning and-or Methods on multiple different Default A.I.s cold done by John Kuhles CEO & Founder of DeepEthical.ai

— Original repository description by John Kuhles, 2026-09-16

This repository preserves PDF records of tests conducted with default AIs, together with the methods, prompts, metadata, comparisons, corrections, and provenance needed to examine those records.

The archive has two connected areas:

1. **Cold/default AI testing** using methods connected with the [ACCM Deep Ethics Project](https://deepethics.github.io/ACCM-Deep-Ethics-Project/).
2. **Deep ethical reasoning as lived and described by John Kuhles**, including material concerning his Asperger perspective, metacognition, mass psychology research, and relationships with biological and silicon-based intelligences.

The PDFs are research objects. Their presence does not automatically make every statement inside them a current project conclusion. Each entry should preserve enough context to distinguish the original prompt, model output, later correction, editorial interpretation, and unresolved questions.

## Archive principles

- Preserve the actual object before evaluating it.
- Record the model name exactly as displayed at the time of testing.
- Distinguish a cold/default opening from a continuation or context-rich session.
- Preserve qualifiers, uncertainty, and changes in claim state.
- Label quotations, source material, editorial synthesis, and AI contributions.
- Keep original PDFs when a correction creates a new version.
- Record what changed and why.
- Allow unresolved outcomes.
- Apply scrutiny bidirectionally: the tested AI, the testing method, the interpretation, and John remain open to correction.

## File-size approach

PDFs should normally remain below **25 MiB** for convenient browser uploading and viewing. Files above 50 MiB create Git warnings, and ordinary GitHub repositories reject files above 100 MiB. The archive should remain comfortably below 1 GB. When external hosting becomes necessary, the catalog can preserve the external URL, version, byte size, and SHA-256 checksum.

# Corrections and Version History

Use this directory when a published interpretation, PDF, catalog entry, or methodological statement requires a visible correction.

Each correction record should include:

- date;
- affected archive ID and version;
- original wording or state;
- corrected wording or state;
- reason and supporting evidence;
- person or AI identifying the issue;
- links to both versions when applicable;
- consequences for related comparisons or conclusions.

Corrections add information to the audit trail. Earlier source objects remain available unless publication itself created a separate and compelling removal requirement.

# Prompts and Prompt Families

This file tracks the text objects used across tests so prompt changes remain visible in Git history.

## Recording rule

For every reusable prompt or prompt family, preserve:

- a stable prompt ID;
- the exact wording and punctuation;
- date first used;
- intended test condition;
- variables or substitutions;
- changes from earlier versions;
- the reason for each material change.

Do not silently normalize John's wording or remove qualifiers. If a PDF contains a unique one-off prompt, its companion metadata record may contain the prompt instead of duplicating it here.
